# MyPresentMe 🚀

เว็บ Single Page HTML สำหรับแนะนำตัวและวิเคราะห์โปรไฟล์ส่วนตัว (Personal Profile & Persona Portfolio)

สร้างขึ้นโดยนำข้อมูลประวัติ ทักษะการทำงาน บุคลิกภาพเชิงวิเคราะห์ และบทแนะนำตัวสำหรับแต่ละสถานการณ์ มาจัดแสดงในรูปแบบ Modern Web Design ที่สวยงาม โหลดเร็ว และตอบโจทย์การใช้งานจริง

## ✨ ฟีเจอร์เด่น (Key Features)

1. **ภาพรวมตัวตน & 1-Sentence Summary**:
   - Hero section พร้อมคำสรุปตัวตนในประโยคเดียว
   - การ์ด Dashboard แสดงระดับทักษะ (Skill Radar Bars) และ Tag Cloud
2. **4 มิติสำคัญของชีวิต (4 Core Dimensions)**:
   - ด้านอาชีพและทักษะ (Vue/Nuxt, C# .NET, SQL, SAP, APIs)
   - ด้านความสนใจ & Maker (AI, EV, Battery Pack DIY, 3D Printing)
   - ด้านชีวิตประจำวัน & ครอบครัว (Family First, การเงินคุ้มค่า, Smart Home)
   - เป้าหมายโดยรวม (Practical Efficiency & Rational Decision)
3. **วิเคราะห์พฤติกรรมและลักษณะนิสัย (Behavioral Analysis)**:
   - 5 บุคลิกภาพเด่นพร้อมจุดแข็งเชิงลึก (Data-driven, Value maximizer, Hands-on, Structured, Responsible)
4. **ตารางจุดแข็ง & แนวทางพัฒนา (Strengths & Growth Matrix)**:
   - ข้อควรระวังเรื่อง *Analysis Paralysis* พร้อมแนวทางแก้ไขด้วย **กฎเกณฑ์ตัดสินใจ 3 ข้อ (3-Key Criteria Rule)**
5. **บทแนะนำตัวตามสถานการณ์ (Interactive Intro Deck)**:
   - สลับแท็บได้ 3 รูปแบบ: แบบทั่วไป, แบบมืออาชีพ (LinkedIn/Resume), แบบสะท้อนตัวตน
   - ปุ่ม **"คัดลอกข้อความ" (One-Click Copy)** พร้อมแจ้งเตือนทันที
6. **AI Context & Persona Generator**:
   - เลือกรูปแบบการนำไปใช้งาน (ป้อนให้ AI, LinkedIn, พัฒนาตนเอง, แนะนำตัวทั่วไป) พร้อมสร้าง Markdown ให้คัดลอกได้ทันที
7. **UX/UI ระดับพรีเมียม**:
   - รองรับ **Dark Mode (ค่าเริ่มต้น)** และ **Light Mode** พร้อมจดจำค่าที่เลือก
   - ปุ่ม **"พิมพ์ / บันทึก PDF"** ที่ปรับแต่ง CSS Print Style สำหรับปริ้นต์เรซูเม่ออกมาได้สะอาดตา
   - Responsive เต็มรูปแบบ รองรับทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์

## 📁 โครงสร้างไฟล์ (File Structure)

```text
MyPresentMe/
├── index.html       # โครงสร้างหน้าเว็บหลักและเนื้อหาทั้งหมด
├── style.css        # สไตล์ ดีไซน์ Glassmorphism, ธีมสี, และ Responsive CSS
├── script.js        # ระบบสลับแท็บ, สลับธีม, คัดลอกข้อความ และ AI Generator
└── README.md        # เอกสารแนะนำโปรเจกต์
```

## 🌐 วิธีเปิดใช้งาน (How to Run)

- **วิธีที่ 1**: ดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ใดก็ได้ (Chrome, Edge, Firefox, Safari) ได้ทันที ไม่ต้องติดตั้งโปรแกรมเพิ่มเติม
- **วิธีที่ 2**: ใช้งานผ่าน Live Server ใน VS Code หรือสั่งเปิดด้วย Node / Python Server
